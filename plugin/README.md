# Cargo Belt

A Claude Code mod. While Claude works, a pixel conveyor belt opens above the prompt and Clawd, in a yellow hard hat, runs the line. Reads become cardboard boxes, edits become machined parts, commands become barrels. A failed tool drops a damaged box and flashes the andon light red. When Claude waits for your permission the line stops, Clawd waves and the bubble turns amber. When the turn ends, Clawd raises a checkered flag and the truck drives off with the cargo.

Give the band focus to play: `w` jump, `a` / `d` walk, `s` get off the belt, `e` drop a box. Turn the mod on or off with `/cargo`, and switch pixel size with `/cargo-size`.

See the full README, demo and install steps at https://github.com/KemalHub/cargo-belt.
